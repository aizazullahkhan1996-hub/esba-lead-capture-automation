# ESBA Lead Capture Automation

A business lead-management workflow built with n8n to capture website enquiries, store lead data and organize follow-ups automatically.

## Workflow

Webhook → Google Sheets → HubSpot CRM → Gmail

## Features

- Receives lead information through a webhook
- Stores leads in Google Sheets
- Creates or updates contacts in HubSpot
- Sends an automatic confirmation email
- Reduces manual data entry and missed enquiries

## Tools Used

- n8n
- Webhooks
- Google Sheets
- HubSpot CRM
- Gmail
